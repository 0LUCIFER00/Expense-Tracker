Adding an expense

  1. On the website. Add Expense takes an amount, a description, a date and a category. Pick an account under "Spend From" and the amount comes out of that balance as well as going on the list; leave it empty and the expense is only recorded.
  2. From your phone. Connect WhatsApp in Settings, then send a message like 250 coffee. No signing in, no app.
  3. Dated anything but today. If this account cannot backdate, the entry waits for an admin to approve it and no money moves until then.

What the Settings toggles do

See account balances
Turn it off and every amount disappears for a normal user: the Balance Management page, the figure after an expense, and the WhatsApp balance reply. This is the point of the admin password.
Spend from an account
Whether an expense may reduce a balance, or only be logged.
Backdate or post-date an expense
Without it, an entry dated other than today waits for approval.
See which account was used
Shows the source type and account columns in the expense list.
Remove an expense
Shows the delete button. Removing an entry puts back any money it took.

The toggles describe a normal user. Signed in with your admin password you always have everything, which is why there is nothing to set for yourself.

Still stuck?

Check that the API is running if a page says it cannot reach the server — in development that is npm run dev. For anything else, the quickest fix is usually to sign out and back in, which re-reads your permissions.
